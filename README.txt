MAPATHON 2026

Preparation workspace for the VIT Mapathon 2026.

Folders:
01_GEE     - Google Earth Engine scripts
02_Python  - Python / ML / data-processing scripts
03_QGIS    - QGIS projects, styles and layouts
04_Data    - Input datasets
05_Outputs - Generated maps, rasters, vectors and final outputs
